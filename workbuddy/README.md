# 专家人设目录

每个 `.md` 文件 = 一个专家人设（格式见 [../catalog/README.md](../catalog/README.md)）。

- 目录名必须是 `divisions.json` 里声明的分区键（本目录 = `workbuddy` 分区）
- 文件名只用 ASCII 字母数字与 `._-`（显示名写在 frontmatter 的 `name` 里）
- 多级分组：`workbuddy/frontend/react-expert.md` 也合法（中间层级会显示为标签）
- `README.md` 不会被当作人设，可放心放说明文档

当前示例：
- `coding-expert.md` —— 全栈编程专家
- `daily-assistant.md` —— 日常效率助理

新增专家：复制任一示例改内容 → 提交推送即可。
